# 자동 QA 봇 (tools/qa_sim.js)

실시간 재생 엔진(PLAY)으로 헌터 인생을 흘리며 검사한다. 하루는 60분씩 24번 `PLAY.step` 으로 진행하고(자정마다 배경 인구 계산을 워커로 받는다), 멈추면 봇이 사용자처럼 고른다.

```bash
CHROMIUM=/opt/pw-browsers/chromium NODE_PATH=$(npm root -g) DAYS=120 RUNS=3 node tools/qa_sim.js
MODE=demo   # 데모(SC_BDEMO)로 시작 (기본은 무작위 새 헌터)
STOP=big    # 멈춤 설정. none(기본) = 전부 캐릭터가 결정 / big · each = 멈출 때마다 봇이 무작위로 직접 고르거나 맡김
```

## 검사하는 것
- 오류: pageerror · console error · 요청 실패
- 불변식: 돈 · 기력 · HP · 스트레스 · 시각 범위, 감정 0~100, 성격 1~10, 누적 목록(알림 · 이야기 · 뉴스 · 게이트 · 감정 기록 · 일대기 기록) 상한, 없는 아이템
- 문장: 이야기 창에 undefined · NaN · null · 치환 안 된 `{x}` · 조사 표시 `이(가)` 가 남았는지
- 화면: 메뉴 네 묶음의 모든 화면 + 일정표 · 뉴스, 각 화면 탭 클릭, 500ms 넘게 걸리는 화면
- 30일마다 하루 평균 계산 시간, 끝에 저장 크기 · 큰 항목 · 저장 왕복
- 통계: 주당 공략 수 · 클리어 · 사망 · 고비 · 감정 · 성격 변화 · 이야기 종류별 줄 수
