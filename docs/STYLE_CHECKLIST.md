# 콘텐츠 스타일 결정 목록

사용자가 Gemini와 상의해서 채우는 문서야. 결정이 들어오면 Codex 외주 의뢰서의 스타일 부분이 돼. 의뢰서는 사용자와 상의한 뒤에 만들어.

**게임 소개 (Gemini에게 줄 때):** 2026년 현실 한국에 게이트가 생긴 세계야. 내가 커스터마이징한 헌터의 인생이 하루 30초 속도로 저절로 흘러가고, 화면에는 그날 일이 문장으로 흘러. 플레이어는 지켜보다가 원할 때 끼어들어. 『80억분의 1』의 매우 디테일한 헌터 버전이라고 생각하면 돼.

각 항목 옆 `→` 뒤에 결정을 적어.

## A. 문장 형식
1. 시점: 3인칭 / 2인칭 / 1인칭 →
2. 시제: 과거형("일어났다") / 현재형("일어난다") →
3. 캐릭터를 부르는 방식: 이름 / 성+이름 / 대명사 섞기 →
4. 한 줄 길이: 짧게 끊기 / 문단형 →
5. 대사 표기: 따옴표 / 메신저 말풍선 / 둘 다 →

## B. 톤과 문체
6. 전체 결: 담담한 현실 드라마 / 웹소설 / 건조한 기록체 / 장면별로 섞기 →
7. 공략 · 전투 장면의 결: 일상과 같게 / 더 과장되게 →
8. 유머: 없음 / 상황 유머만 / 적극적 →
9. 감정 묘사 깊이: 행동만 / 속마음까지 →
10. 존댓말 · 반말: NPC 말투 기준 (나이 · 관계별) →

## C. 세계의 현실감
11. 현실 생활 요소 비중 (편의점 · 지하철 · 월세 · 배달 · 단톡방 등) →
12. 헌터라는 직업의 느낌: 화려한 직업 / 위험한 노동 / 둘 다 →
13. 게이트가 생긴 지 몇 년 됐는지, 사회가 얼마나 적응했는지 →
14. 시스템 요소 범위: 상태창만 / 퀘스트 · 알림창 같은 게임 시스템까지 →
15. 언론 · SNS · 커뮤니티의 비중 →

## D. 인물 · 길드 · 이름
16. 길드 규모 구조: 대형 몇 개, 중소 몇 개 →
17. 이름 있는 상위 헌터의 규모와 성격 (유명인처럼? 은둔형?) →
18. 인물 이름 짓기 규칙: 실제 한국 이름 분포 / 개성 있는 이름 →
19. 길드 · 단체 이름 스타일: 한자어 / 순우리말 / 영어 / 회사식 →
20. 실존 인물 · 기업 · 지명 사용 범위 (지명은 지금 실제 지명을 씀) →
21. 외국 헌터 · 해외 길드 비중 →

## E. 수위와 금지
22. 폭력 · 부상 · 사망 묘사 수위 →
23. 연애 · 신체 묘사 범위 (성적 묘사 금지는 고정) →
24. 외모 평가 · 비하 표현을 다루는 방식 →
25. 욕설 · 비속어 허용 정도 →
26. 다루지 않을 주제 (자해, 미성년 관련 등) →
27. 사회 문제(빈부 · 차별 · 정치)를 다루는 정도 →

## F. 사건의 결
28. 일상 사건과 큰 사건의 비율 느낌 →
29. 결말이 해피엔딩 / 새드엔딩 쪽으로 기우는 정도 →
30. 선택지의 성격: 정답 있음 / 정답 없는 딜레마 위주 →
31. 반복되는 인물(라이벌 · 단짝)이 얼마나 자주 엮이는지 →
32. 운 · 우연의 비중 →

## G. 분량과 다양성
33. 같은 상황의 문장 변형 개수 (반복감 줄이기) →
34. 성격 · 외모 · 출신별로 문장을 얼마나 다르게 쓸지 →
35. 지역색(사투리 · 지역 문화) 반영 여부 →

## H. 재료별 스타일 (위 기준을 재료마다 다르게 할지)
36. 하루 행동 문장 →
37. 작은 일 · 만남 →
38. 이벤트 (선택지 있는 사건) →
39. 공략 장면 · 위기 →
40. 뉴스 헤드라인 / 소문 / 들은 이야기 →
41. 아이템 · 몬스터 · 클래스 · 스킬 설명 →
42. 길드 · 인물 설정 문서 →
