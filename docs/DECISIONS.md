# 설계 결정 기록 (K-Hunter-Life)

우선순위: **사용자의 최근 결정 > 이 문서의 확정 결정 > REBUILD_PLAN · STYLE_CHECKLIST > 옛 버전에서 이어받은 결정 > Claude 임시값**.
'Claude 결정'은 사용자가 "한 번에 만들어 줘(단계마다 확인받지 말고)"라고 해서 Claude 가 합리적으로 정한 것 — 사용자가 바꾸면 바로 고친다.

## 1. 사용자 결정 (2026-10-23, REBUILD_PLAN · STYLE_CHECKLIST)

| 주제 | 결정 |
|---|---|
| 정체성 | 『80억분의 1』의 매우 디테일한 버전. 시뮬레이션이 돌고 중간에 끼어들어 조금 플레이. 커마한 헌터의 인생이 하루 단위로 흘러간다 |
| 시간 | 하루 30초(×1). 배속 · 일시정지 · 다음 사건까지. 옛 '계속' 버튼 · 진행 메뉴 없앰. 오프라인 진행 없음 |
| 문장 | 상세도 기본 '자세히', 요약 · 보통 가능. 공략은 장면으로 (입장 → 구역 → 위기 → 보스 → 결과). 세상 소식이 섞인다 |
| 개수 | 하루의 일 · 사건 · 만남 · 공략 수를 미리 정하지 않는다. 이야기꾼은 B안(조용하면 살짝 올리고 몰리면 살짝 낮춤) |

| 판단 엔진 | 하루 일정 · 이벤트 · 위기를 하나의 엔진이. NPC 도 같은 엔진. 태그 × 재료 + 약간의 무작위. 이유 문장. 경험이 성격을 바꾼다 |

| 끝 | 사망 · 은퇴 · 노년을 짧게 흘린 뒤 생을 마침. 일대기 한 장 · 작별 한마디. 고비 회고 + 한 줄 |
| 이어 가기 | A 같은 세계(새 인물 · 플레이 중 인물 바꾸기) · B 기록관(시점 · 관계 골라 새 게임에) · C 파일. 모두 반영 |
| 화면 | 인생 화면이 중심. 메뉴 네 묶음(제안) — "일단 해 보는 걸로" |
| 만드는 방식 | 한 번에 만들고, 테스트 · QA 봇으로 충분히 돌려 보고 넘긴다 |
| 세계 | 2026년 현재 · 1999년 첫 게이트(27년) · 각성 0.5% · 활동 0.2% · 망한 나라 있음(내용은 Codex 세계관 외주) · 날짜 · 지도 · 물가는 2026 그대로 |
| 콘텐츠 | 모든 콘텐츠는 Codex 외주. 스타일은 STYLE_CHECKLIST (18세 · 성적 묘사 포함(성인만) · 비하 · 혐오는 인물의 말로만). 의뢰서는 사용자와 상의한 뒤 |
