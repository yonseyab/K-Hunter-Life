# 커마 항목별 쓰임 (세 층 원칙 · REBUILD_PLAN 2장)

**세상은 사실대로 반응하고, 마음은 성격대로 받아들인다.**
- 1층 **사실** = 커마 값 그대로 (외모 점수 `looksOf` · 키 · 체중 · 출신 · 가정 형편 · 성격 수치 …)
- 2층 **세상의 반응** = 사실 × 상대의 취향 · 성격 (`impression` · `tasteOf`). 사실과 반대되는 반응은 나오지 않는다 (`asserts` 검사). 비꼬는 말은 질투하는 특정인에게서만 (`react:jealous`)
- 3층 **마음(자기 인식)** = 사실 기준선 + 성격(비관 · 낙관) + 들은 말 (`SELF`, 기준선에서 ±25 넘게 안 벗어남)

커마 값은 **능력치 효과가 아니다** (옛 결정 유지). 아래 네 가지로만 쓰인다. ✓ = 지금 엔진이 쓰고 있음, ○ = 데이터(외주)만 채우면 됨 (조건 키가 있음).

| 커마 항목 | ① 일어날 수 있는 사건 | ② 남들의 반응 | ③ 본인의 선택 (판단 엔진) | ④ 문장 묘사 |
|---|---|---|---|---|
| 외형 (얼굴 · 몸 · 분위기 · 스타일 점수 `APS_`) | ○ `looks` 조건 이벤트 (예 EV_B0007 사진 요청) | ✓ `react:looksHi/Lo/jealous` · 관계 첫인상 `impression` | ✓ 자기 인식 `self:looks` → 연애 적극 · 체면 태그 | ○ 묘사 문장에 asserts |
| 외형 선택지 (머리 · 의상 · 컵 등 `LK_`) | ○ `look` · `lookNum` · `bmi` 조건 | ○ 같은 조건의 반응 문장 | — | ✓ 체격 `{build}` (키 · 체중) 공략 장면 · 파티 소개 |
| 체형 (키 · 체중) | ○ `lookNum` · `bmi` | ○ | — | ✓ `{build}` |
| 목소리 · 말투 | ○ `basic` 조건 (voice · speech) | ○ | — | ○ 대사 문장 변형 |
| 출신 · 국적 · 출생지 · 언어 | ○ `basic` · `lang` 조건 · 망한 나라 출신(`ccNations.state`) | ○ | — | ✓ 시작 전 인생 요약 `prologue` · ○ 사투리(STYLE 35) |
| 가정 형편 · 학력 · 이전 직업 · 과거 (`BI_`) | ○ `bg` 조건 | ○ | ✓ 자기 인식 `self:money` 기준선은 돈 사실 | ✓ 시작 전 인생 요약 |
| 가족 · 거주 환경 | ✓ 가족 관계 → 가족 이벤트(EV_B0001) · 가족의 죽음 고비 | ✓ 가족 메시지 · 같이 사는 사람 | ✓ 소속감 `self:belong` | ✓ 만남 · 작은 일(`small:PT_HOME`) |
| 성격 8축 + 세부 | ○ `pers` 조건 | ✓ NPC 도 같은 판단 엔진(`MIND.npcScore`) | ✓ **모든 선택**(태그 × 성격) · 무작위 크기(즉흥성) · 감정 반감기(표현) · 불안 · 우울 세기(비관) | ✓ 이유 문장 "겁 많은 ~은 결국 …" |
| 특성 (`TR_`) | ○ `trait` 조건 | ○ | — (효과 미정, 옛 결정) | ○ |
| 나이 · 성별 | ○ `age` · `sex` · `adult` 조건 | ✓ 성인끼리만 관능미 · 연애 감정 | — | ✓ 생일 · 노년 |
| 클래스 · 역할 · 스킬 | ○ `cls` 조건 | ✓ 파티 소개 | ✓ 공략 전력 · 위기 판정 | ✓ `{cls}` `{role}` `{gear}` 공략 장면 |

## 엔진이 쓰는 재료 (판단 엔진 `MIND`)
- 성격(px) · 지금 상태(HP · 기력 · 스트레스 · 수면 · 돈 · 부상) · 감정(EM_) · 자기 인식(self) · 관계(호감 · 신뢰 · 친밀 − 원망) · 기억(최근 이벤트에서 그 사람과 있었던 일) · 방침(pol: risk · money · team · rest).
- 큰 사건(공략 성공 · 실패 · 큰 부상 · 동료의 죽음 · 연애 · 이별 · 승급 · 결혼 · 길드 입단 · 친절 · 이기적 선택)은 성격 축을 아주 조금씩 움직인다 (`MIND.drift`, 한 축 최대 ±3). 일대기에 남는다.
