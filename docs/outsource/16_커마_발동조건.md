# 16. 커마 선택 → 이벤트 · NPC 대사 발동 조건

캐릭터를 만들 때 고른 값(외형 · 기본 정보 · 출신 배경 · 성격 · 특성 · 클래스)은 **능력치에 효과를 주지 않는다.** 대신 이벤트와 NPC 대사가 **발동하는 조건**으로 쓴다. (사용자 결정 2026-10-23)

예시로 생각하는 방향:

- 가슴이 아주 큰 여자 → 옷을 살 때 맞는 사이즈가 없어 곤란하다 · "가슴 크다"는 말을 듣는다
- 마른 남자 → "너무 말랐다", "비실이" 같은 말을 듣는다
- 몸매가 좋은 여자 → 화보 촬영 제의가 들어온다
- 몸이 좋은 남자 → 속옷 광고 제의가 들어온다

이 문서는 **조건을 쓰는 법**만 정한다. 이벤트 문장 자체는 [01_이벤트_일상.md](01_이벤트_일상.md) 형식(`events`)을 따른다. 커마 선택지는 아직 다 정해지지 않았으니, 조건에 쓰는 선택지 ID는 항상 최신 [ID_참조.md](ID_참조.md)에서 확인한다.

## 조건 쓰는 법

이벤트의 `req` 배열에 아래 조건을 넣는다. 배열에 있는 조건은 **모두** 맞아야 발동한다. 여럿 중 하나만 맞으면 될 때는 `{k:'any', of:[…]}`, 반대는 `{k:'not', q:{…}}`.

`who:'tgt'` 를 붙이면 플레이어가 아니라 **대상 인물**(그 이벤트의 상대 NPC)을 본다. 붙이지 않으면 플레이어.

| 조건 | 형식 | 뜻 |
|---|---|---|
| 외형 선택 | `{k:'look', item:'LK_CHEST_S', in:['SZ_5']}` | 외형 항목(LK_)이 목록 중 하나 |
| 외형 수치 | `{k:'lookNum', item:'LK_HEIGHT', min:185}` | 키 · 체중 같은 슬라이더 항목. min · max 중 하나 이상 |
| 체질량지수 | `{k:'bmi', max:18}` | 체중 ÷ 키(m)². 마름 18.5 미만, 비만 25 이상 정도 |
| 출신 배경 | `{k:'bg', item:'BI_JOB', in:['JB_0004']}` | 출신 · 배경 항목(BI_). 복수 선택 항목은 하나라도 있으면 참 |
| 성격 | `{k:'pers', axis:'PX_EXTRO', min:8}` | 성격 축(PX_) 1~10단계. 1에 가까울수록 왼쪽(내향 등), 10에 가까울수록 오른쪽(외향 등) |
| 성별 | `{k:'sex', v:'남'}` | '남' · '여' |
| 나이 | `{k:'age', min:30}` | min · max |
| 기본 정보 | `{k:'basic', key:'blood', in:['AB']}` | key: blood(혈액형) · hand(주로 쓰는 손) · nation(국적) · bplace(출생지) · langMain(모국어) · voice(목소리) · speech(말투) |
| 쓰는 언어 | `{k:'lang', id:'LANG_JA'}` | 모국어 · 추가 언어 중에 있으면 |
| 특성 | `{k:'trait', id:'TR_0001'}` | 특성을 가지고 있으면 (`who:'tgt'` 가능) |
| 클래스 | `{k:'cls', in:['CLS_0001']}` | |

기존 조건(시간대 · 장소 · 관계 · 돈 · 스트레스 등)과 섞어 쓸 수 있다. 전체 목록은 [01_이벤트_일상.md](01_이벤트_일상.md).

## 예시 (조건만)

```js
// G컵 이상인 여자 · 아침이나 낮 (옷을 살 때 곤란)
req:[{k:'sex', v:'여'}, {k:'look', item:'LK_CUP', in:['CUP_G','CUP_H','CUP_I']}, {k:'slot', in:[0,1]}]   // slot: 0 아침 · 1 낮 · 2 저녁 · 3 밤

// 마른 남자 (체질량지수 18 이하 또는 근육량 매우 적음)
req:[{k:'sex', v:'남'}, {k:'any', of:[{k:'bmi', max:18}, {k:'look', item:'LK_MUSCLE', in:['AM_1']}]}]

// 몸매가 좋은 여자에게 화보 제의 (몸매 수준 높음 이상 · 평판 20 이상)
req:[{k:'sex', v:'여'}, {k:'look', item:'LK_FIGURE', in:['LV_4','LV_5']}, {k:'rep', min:20}]

// 몸이 좋은 남자에게 속옷 광고 제의 (근육량 많음 이상 · 체지방 적음 이하)
req:[{k:'sex', v:'남'}, {k:'look', item:'LK_MUSCLE', in:['AM_4','AM_5']}, {k:'look', item:'LK_FAT', in:['AM_1','AM_2']}]

// 아는 NPC가 외향적인 사람일 때만 하는 말 (대상 인물 기준)
req:[{k:'known'}, {k:'pers', axis:'PX_EXTRO', min:8, who:'tgt'}]
```

## 지금 있는 외형 항목 (2026-10-23 기준)

외모 수준 LK_LOOKS · 몸매 수준 LK_FIGURE · 키 LK_HEIGHT(슬라이더) · 체중 LK_WEIGHT(슬라이더) · 얼굴 크기 · 어깨너비 · 가슴 두께 LK_CHEST_D · 가슴 크기 LK_CHEST_S · 컵 사이즈 LK_CUP(여) · 가슴 형태 LK_CHEST_F · 등 너비 · 팔 굵기 · 허리 굵기 · 허리 굴곡 · 골반 너비 · 엉덩이 크기 · 엉덩이 형태 · 허벅지 굵기 · 다리 길이 · 근육량 LK_MUSCLE · 근육 선명도 · 체지방 LK_FAT · 피부톤 · 피부 상태 · 헤어스타일 · 머리색 · 동안 · 노안 · 외형 분위기 · 의상 스타일.

정도를 고르는 항목의 선택지는 대부분 5단계다 (예: 크기 SZ_1 매우 작음 ~ SZ_5 매우 큼, 수준 LV_1 ~ LV_5, 양 AM_1 ~ AM_5). 여자는 **컵 사이즈 LK_CUP** (CUP_AA · CUP_A · … · CUP_H · CUP_I(I컵 이상))도 있다.

## 검사

`node tools/validate_data.js` 가 조건 종류(k), 필요한 값(item · in · axis · min/max), 없는 ID를 검사한다.
