# 장비 화면 이미지 의뢰 (GPT용)

> 2026-10-24. 사용자가 그린 스케치는 틀을 잡기 위한 예시일 뿐이라 똑같이 그릴 필요는 없다. 아래 지시문을 그대로 GPT에게 붙여 넣는다.

---

한국 현대 배경 헌터물 + 성좌물 웹 게임 「K-Hunter-Life」의 **'상태창 › 장비' 화면 UI 시안 이미지**를 만들어 줘.

**게임 설명**
- 플레이어는 헌터를 직접 조종하지 않아. 헌터를 지켜보는 '성좌'야.
- 그래서 이 화면은 **헌터가 지금 착용하고 있는 장비만 보여 주는 화면**이야. 가방 · 인벤토리 목록 · 착용 / 해제 버튼은 없어. 무엇을 입을지는 헌터가 정해.

**보여 줄 것**
1. 사람 모양(실루엣 또는 단순한 선 그림) 주위에 착용 칸 8개
   - 무기: 오른손 쪽
   - 보조: 왼손 쪽 (방패 · 보조 무기)
   - 상의 · 하의: 몸통 위아래
   - 귀 · 목 · 손: 장신구 세 칸 (손 = 반지 · 팔찌)
   - 특수: 따로 떨어진 한 칸 (정체 모를 유물 같은 특별한 물건)
2. 두 칸을 같이 차지하는 경우
   - 양손 무기는 무기 + 보조 칸을 같이 차지해
   - 한 벌짜리 옷은 상의 + 하의 칸을 같이 차지해
   - 이 두 경우를 어떻게 보여 줄지 시안에 넣어 줘
3. 칸 하나에 들어가는 정보: 물건 이름, 등급, 내구도 막대
   - 등급은 일반 · 고급 · 희귀 · 영웅 · 전설 (숨은 '신화'도 있음), 색으로 구분
   - 망가진 장비(내구도 0)와 빈 칸의 모습도 보여 줘
4. 옆에 작은 요약 칸: 무기 판정 보정, 공략 전력, 받는 피해 감소, 장비 개성(예: 날카로움 +1, 무거움 −1)

**스타일**
- 어두운 화면. 기존 화면처럼 작은 사각형 상자 · 얇은 선 · 작은 글씨
- 장식이나 큰 여백은 넣지 않아
- 판타지 게임처럼 화려하게 하지 말고, 현대 한국 앱처럼 깔끔하게

**크기 · 배치**
- 데스크톱 화면(가로 약 1000px 영역)에 하나
- 휴대폰 폭(360px)에서 세로로 쌓인 모습에 하나

**넣지 말 것**
- 가방 · 인벤토리 격자
- 착용 · 해제 · 판매 버튼
- 실제 게임 · 브랜드 로고, 기존 작품의 캐릭터

**결과물:** 시안 이미지 2장 (데스크톱 · 모바일)과 각 칸의 배치 설명 몇 줄
