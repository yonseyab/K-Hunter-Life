# 게이트 · 몬스터 데이터 형식 (2026-10-24)

> **형식만.** 사용자 결정: 지금은 데이터 형식만 정하고, 몬스터 · 꼬리표 · 약점 · 부위 목록은 나중에 다른 데이터와 한꺼번에 외주한다. 의뢰 문장은 그때 쓴다.
> 파일: `game/data/content.js` (몬스터 · 표), `game/engine/monster.js` (게이트 구성 · 브레이크 분류), 검사: `game/engine/validate.js`

## 몬스터 `monsters`

```js
{id:'MON_XX00001', name:'고블린', cat:'MC_HUMANOID', ranks:['RANK_20','RANK_17'], size:'MSZ_S',
 tags:['MTAG_PACK'], weak:['EL_FIRE'], resist:[], habitats:['GI_CAVE','GI_FOREST'], boss:false,
 drops:[{item:'IT_…', chance:0.3, qty:1}], desc:'무리를 짓는 작은 인간형.'}
```

| 필드 | 뜻 |
|---|---|
| `cat` | 계열 `monsterCats` (인간형 · 마수 · 부정형 · 언데드 · 곤충형 · 미분류) |
| `ranks` | 등급 범위 `[약한 쪽, 센 쪽]`. 같은 종이라도 개체마다 세기가 다르다 (옛 `rank` 하나도 받아 줌) |
| `size` | `monsterSizes`: 소형 · 중형 · 대형 · 거대 |
| `tags` | 행동 꼬리표 `monsterTags` (`MTAG_…` — 무리 · 매복 · 돌진 · 원거리 · 재생 …) |
| `weak` · `resist` | 약점 · 저항 `elements` (`EL_…` — 불 · 냉기 · 빛 · 둔기 …) |
| `habitats` | 나오는 내부 지형 `gateInteriors` (없으면 어디든) |
| `boss` | 보스 전용이면 `true` |
| `drops` | 따로 정한 드롭. 소재는 계열 × 부위 규칙으로도 연결된다 (아래) |

## 표 (형식만, 비어 있음)

- `monsterTags` · `elements` · `matParts`: `{id, name, desc}`
- 소재 아이템: `items` 에 `matCat`(monsterCats) · `matPart`(matParts) — 계열 × 부위로 그 계열 몬스터와 자동 연결 (연결 코드는 나중)

## 게이트 구성

- 게이트 하나 = **잡몹 1~3종 + 보스 1** (`g.mobs` · `g.boss`). 게이트 등급이 몬스터 등급 범위 안에 드는 것, 지형(`habitats`)이 맞는 것에서 고른다 (`MONSTER.compose`). `g.mon` 은 옛 엔진 호환 = 첫 잡몹.

## 특별한 게이트 `gateKinds`

- 게이트의 `kind` 필드. 없으면 일반 게이트.
- 지금은 **브레이크** 하나 (`GK_BREAK`, 시간이 다 돼 몬스터가 밖으로 넘치면 엔진이 붙인다).
- 이레귤러 · 고정 · 이벤트 게이트 같은 분류는 게임이 완성된 뒤 업데이트로 늘린다 — `{id:'GK_…', name, desc, auto?}` 한 줄 추가.
