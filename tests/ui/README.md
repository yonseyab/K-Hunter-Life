# UI 스모크 테스트

`game/index.html` 을 Playwright(Chromium)로 열어 주요 흐름을 실제로 눌러 보고, **페이지 오류가 없는지**(`errs []`)와 일부 결과 값을 출력한다.
정답 비교 테스트가 아니라 "부서지지 않았는지" 확인용이다. 출력 값은 사람이 보고 판단한다.

```bash
npm i -D playwright            # 또는 전역 설치 후 NODE_PATH=$(npm root -g)
CHROMIUM=/path/to/chromium node tests/ui/run_all.js
node tests/ui/t_gate.js        # 하나만
```

옛 버전 테스트는 `fixture.js`(테스트 전용 고정 게이트 · 이벤트 · 아이템)를 `page.goto` 뒤에 넣어서 돈다. 콘텐츠(외주)가 바뀌어도 테스트가 흔들리지 않게 하려는 것.
