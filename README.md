# K-Hunter-Life

헌터 라이프 새 버전이야. 2026년 현실 한국에 게이트가 생긴 세계(1999년 첫 게이트)에서, 커스터마이징한 헌터의 인생이 하루 30초로 흘러가고 플레이어는 그 헌터의 성좌로서 지켜보며 코인으로 선물해.

- 실행: `game/index.html` 을 브라우저로 연다 (빌드 없음).
- 지금 상태 · 구조: [docs/HANDOFF.md](docs/HANDOFF.md) · 결정: [docs/DECISIONS.md](docs/DECISIONS.md)
- 콘텐츠 스타일: [docs/STYLE_CHECKLIST.md](docs/STYLE_CHECKLIST.md) · 경제: [docs/ECONOMY.md](docs/ECONOMY.md)
- 검사: `node tools/validate_data.js` · `node tests/ui/run_all.js` · `node tools/qa_sim.js` ([docs/QA.md](docs/QA.md))
- 옛 버전: [yonseyab/Hunter-Life](https://github.com/yonseyab/Hunter-Life)
